🚀 วิธีนำเว็บนี้ขึ้น GitHub Pages ให้คนอื่นใช้งานได้ฟรี:
  1. สร้าง Repository ใหม่บน github.com (ตั้งชื่อเช่น checkdan-th)
  2. อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมดขึ้นไปบน Repository
  3. ไปที่แท็บ Settings → Pages → เลือก Branch: main → กด Save
  4. คุณจะได้ลิงก์เว็บพร้อมใช้ทันที เช่น https://<username>.github.io/checkdan-th/
