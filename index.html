โทรออกได้ทันที (คลิกปุ่มโทร):

เชื่อมต่อ & นำเข้าข้อมูล TrafficD Lite (จราจร ด่าน รถติด)

เกี่ยวกับการเชื่อมต่อแอป TrafficD Lite
แอป TrafficD Lite จราจร ด่าน รถติด เป็นแอปพลิเคชันระบบปิดของผู้พัฒนา (ไม่มี Public API ให้เว็บไซต์ดึงตรงๆ ผ่าน Web Browser ได้โดยตรงเนื่องจากติด CORS) แต่ระบบ CheckDan ได้เตรียมฟังก์ชันนำเข้าข้อมูล (Data Importer) และเปิดสลับแอปคู่ขนาน เพื่อให้ใช้งานร่วมกันได้อย่างสมบูรณ์แบบครับ
สลับไปเปิดแอป TrafficD Lite บนโทรศัพท์
เปิดแอป TrafficD Lite เพื่อเช็คกล้อง CCTV ดูภาพสดบนถนน หรือตรวจสอบรายงานรถติด แล้วสลับกลับมาฟังเสียงเตือนเรดาร์ของ CheckDan ได้ทันที
เว็บ TrafficD Map
นำเข้าข้อมูลจุดด่าน / กล้องเรดาร์ (JSON / ข้อความ)
วางข้อมูลจุดตรวจ กล้องตรวจจับความเร็ว หรือพิกัดที่คัดลอกจาก TrafficD หรือกลุ่มรายงานด่าน เพื่อเพิ่มเข้าระบบเรดาร์เสียงเตือนทันที
เชื่อมต่อ Webhook / Custom API Proxy
หากคุณมี API Backend หรือบริการดึงข้อมูล TrafficD สามารถใส่ URL เพื่อดึงข้อมูลมาซิงค์กับ CheckDan อัตโนมัติ:

🚀 วิธีนำเว็บนี้ขึ้น GitHub Pages ให้คนอื่นใช้งานได้ฟรี:
  1. สร้าง Repository ใหม่บน github.com (ตั้งชื่อเช่น checkdan-th)
  2. อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมดขึ้นไปบน Repository
  3. ไปที่แท็บ Settings → Pages → เลือก Branch: main → กด Save
  4. คุณจะได้ลิงก์เว็บพร้อมใช้ทันที เช่น https://<username>.github.io/checkdan-th/
