# 🧭 คู่หูนักเดินทาง (Travel Companion TH) - ระบบตรวจสอบด่านจราจร นำทางท่องเที่ยว & โหมดขับขี่ HUD (77 จังหวัด)

เว็บแอพพลิเคชันแบบตอบสนอง (Responsive Web App) สไตล์ **Cyber Dark Radar & Glassmorphism** ในชื่อ **"คู่หูนักเดินทาง"** สำหรับตรวจสอบและรายงานจุดตรวจด่านจราจร ด่านเป่าแอลกอฮอล์ ด่านตรวจควันดำ กล้องตรวจจับความเร็ว **ค้นหาแหล่งท่องเที่ยว 77 จังหวัดทั่วไทย วางแผนเส้นทางและสแกนด่านตลอดสาย** พร้อมระบบสถิติและข้อมูลผู้ติดตั้งโปรแกรม (สำหรับผู้ดูแลระบบ) รองรับการเปิดใช้งานบน **GitHub Pages ฟรี 100%**

---

## ✨ ฟีเจอร์เด่นของ "คู่หูนักเดินทาง"

1. **ระบบค้นหาแหล่งท่องเที่ยว 77 จังหวัด (Tourist Attractions Explorer):**
   - ฐานข้อมูลแหล่งท่องเที่ยวยอดนิยมครบทุกภาคทั่วไทย (ธรรมชาติ, ภูเขา, ทะเล/เกาะ, วัด/มรดกโลก, แลนด์มาร์ก, ตลาด, คาเฟ่)
   - ค้นหาแบบเรียลไทม์ กรองตามจังหวัด และปุ่มลัด "ที่เที่ยวใกล้ฉัน (Nearby Attractions)"
   - แสดงหมุดและเลเยอร์บนแผนที่ Leaflet พร้อมไฮไลต์ ค่าเข้าชม และระยะทาง
   - ปุ่ม **"นำทางทันที"** เปิดระบบนำทาง Turn-by-Turn เลี้ยวต่อเลี้ยว พร้อมปุ่ม **"สแกนทาง"** ตรวจจับด่านตลอดเส้นทางท่องเที่ยว

2. **ระบบสถิติและวิเคราะห์ข้อมูลอุปกรณ์และการติดตั้งจริง (Real Device Telemetry & Installation Audit):**
   - แสดงสถานะการติดตั้งจริงของอุปกรณ์ (Standalone PWA vs Web Browser) ตรวจจับจาก Client โดยตรง ไม่ใช้ตัวเลขจำลอง
   - บันทึกการเข้าใช้งานจริง (Real Sessions Count) และประวัติการติดตั้งบนเครื่องของผู้ใช้
   - เข้าดูข้อมูลและสเปกจริงได้โดยการ **Login เป็น Admin** (รหัสผ่านเริ่มต้น `admin1234`)
   - แสดงแดชบอร์ดฮาร์ดแวร์จริง: ระบบปฏิบัติการ (OS), เว็บเบราว์เซอร์, ความละเอียดหน้าจอ, พื้นที่แคชออฟไลน์, สถานะเครือข่าย
   - บันทึกประวัติกิจกรรมจริง (Chronological Activity Audit Log) และปุ่มดาวน์โหลดรายงาน Telemetry แบบ JSON

3. **ระบบวางแผนเส้นทาง & สแกนด่านตลอดสาย (Route Planning & Scanner):**
   - คำนวณเส้นทางการขับขี่ระหว่างจุดเริ่มต้น (หรือพิกัดปัจจุบัน) ไปยังจุดหมายปลายทาง
   - แสดงเส้นทางขับขี่ด้วยเส้นนีออนเรืองแสง (Glowing Route Polyline) พร้อมปักหมุดจุดเริ่มต้น (🟢) และจุดหมายปลายทาง (🏁)
   - อัลกอริทึมสแกนตรวจจับจุดตรวจด่านที่อยู่บนแนวเส้นทางหลวงโดยอัตโนมัติ
   - แสดงระยะทางรวม, เวลาเดินทางโดยประมาณ และลิสต์ลำดับด่านที่ต้องผ่านตั้งแต่ต้นจนจบทาง

4. **ครอบคลุมครบ 77 จังหวัดทั่วประเทศไทย:**
   - มีเมนู Dropdown เลือกดูจุดตรวจแยกตามรายจังหวัดทั้ง 77 จังหวัด จัดหมวดหมู่ตามภาค
   - แผนที่บิน (FlyTo) ไปยังพิกัดจังหวัดที่เลือกอัตโนมัติ

5. **เรดาร์เตือนระยะประชิด & เสียงพูดภาษาไทยอัตโนมัติ:**
   - คำนวณระยะห่างระหว่างผู้ใช้กับด่านและกล้องความเร็วที่ใกล้ที่สุดแบบเรียลไทม์
   - ป้ายเตือน HUD Banner ป้องกันการชนทับซ้อน พร้อมเสียงพูดขานเตือนภาษาไทย

6. **ระบบความปลอดภัยและการจัดการเฉพาะผู้ดูแล (Admin Access Control):**
   - เข้าสู่ระบบ Admin ได้โดยคลิกไอคอนแม่กุญแจ `[ 🔒 ]` มุมขวาบน (รหัสผ่านเริ่มต้น: `admin1234`)
   - จัดการซิงค์ GitHub, ดาวน์โหลดข้อมูล checkpoints.json, เปลี่ยนรหัสผ่าน Admin และดูข้อมูลผู้ติดตั้งโปรแกรม

81: ## 🧭 ระบบนำทางเลี้ยวต่อเลี้ยว (Turn-by-Turn Navigation เหมือน Google Maps)
82: 
83: - **แบนเนอร์เลี้ยวด้านบน (Turn Instruction Banner)**: แสดงไอคอนเลี้ยว, ระยะทางนับถอยหลัง, และชื่อถนนหรือป้ายบอกทางภาษาไทย
84: - **แถบสรุปข้อมูลด้านล่าง (Bottom Trip Bar)**: แสดงระยะทางคงเหลือ (กม.), เวลาคงเหลือ (นาที), เวลาถึงโดยประมาณ (ETA), มาตรวัดความเร็วสด (km/h) และปุ่มหยุดนำทาง
85: - **ไอคอนรถนำทางหมุนตามทิศทางจริง**: ตัวรถสีฟ้าเรืองแสงพร้อมวงเรดาร์หมุนตามทิศทางมุมองศา (Bearing Angle) ของถนน
86: - **เสียงพูดนำทางอัตโนมัติ**: แจ้งเตือนเลี้ยว, เตือนด่านตรวจข้างหน้า, เตือนกล้องจับความเร็ว และเตือนจุดอันตรายด้วยเสียงพูดภาษาไทย
87: - **บันทึกสรุปผลการเดินทาง (Trip Analytics)**: เมื่อถึงที่หมาย จะสรุปความเร็วเฉลี่ย, ความเร็วสูงสุด, ระยะทาง, จำนวนด่าน/กล้องที่ผ่าน พร้อมปุ่มแชร์ลงโซเชียล
